# Home — Estrutura e Copy

## 1. Objetivo da página

Converter atenção em ação. A Home não é um portfólio. Ela é uma porta de entrada para o sistema.

Objetivo principal: levar o visitante para o bot Telegram.
Objetivo secundário: fazer o visitante ler um artigo.
Objetivo terciário: preparar o visitante para o curso.

## 2. Posicionamento

Marca: Ensinamentos da Vida.
Tom: direto, confrontacional, estoico, segunda pessoa.
Inimigo comum: motivação barata, coach genérico, promessa mágica, procrastinação disfarçada de planejamento.
Promessa central: transformar intenção em comportamento.

## 3. Mensagem central

Você não precisa de motivação. Precisa de sistema.

## 4. Hierarquia de conversão

1. CTA principal: Iniciar o bot.
2. CTA secundário: Ler artigos.
3. CTA de futuro: Conhecer o curso.

Regra: a Home pode ter vários caminhos, mas todos devem apontar para uma única decisão inicial. Começar pelo bot.

## 7. Regras de copy

- Escrever em segunda pessoa.
- Frases curtas.
- Cortar adjetivos inúteis.
- Nada de tom acadêmico.
- Nada de coach genérico.
- Usar uma frase de impacto a cada 2 ou 3 blocos.
- Todo bloco precisa ter função: prender, conscientizar, converter ou provar.
- Se o bloco não empurra para ação, cortar.
